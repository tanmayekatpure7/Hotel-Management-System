# Hotel Management System

A Java Swing-based Hotel Management System that allows hotel staff to manage room bookings, calculate charges automatically, and generate customer bills through a user-friendly graphical interface.

## Features

* Secure Login System

  * Username and password authentication
  * Access control before booking

* Room Booking Management

  * Guest name and contact details
  * Number of stay days
  * Room selection:

    * Standard Room
    * Deluxe Room
    * Suite Room

* Food Selection

  * No Food
  * Veg Meal Plan
  * Non-Veg Meal Plan

* Payment Options

  * Cash
  * Card
  * UPI

* Automatic Bill Generation

  * Room charges calculation
  * Food charges calculation
  * GST (18%) calculation
  * Final amount calculation

* Receipt Generation

  * Hotel bill receipt
  * Date and time stamp
  * Guest details
  * Booking summary

## Technologies Used

* Java
* Java Swing
* AWT Event Handling
* Object-Oriented Programming (OOP)
* Java Date & Time API
